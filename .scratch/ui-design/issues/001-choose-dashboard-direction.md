# 001: Choose a dashboard direction

Status: implemented.

The compact direction was carried into the responsive dashboard. The implemented overview includes the available cash balance and month navigation, income and expense summaries, recent transactions, budget check-in, and recurring occurrence review. Desktop and mobile layouts are handled by the dashboard grid and responsive styles; the app has no dashboard `?variant=` switcher.

The design exploration and selection are complete. The issue's remaining work (reviewing alternatives, promoting the selected direction, and removing the prototype switcher) is no longer outstanding.
