# Dashboard design exploration

## Question

Which dark dashboard layout feels clear, personal, and calm without looking overly decorative or template-generated?

## Constraints

- English-first interface, IDR, single-user personal-finance MVP.
- Keep cash balance and recent activity easy to scan.
- Prefer plain language, a mostly charcoal palette, green secondary accents, subtle gradients, restrained frosted glass, and useful density over decorative cards and illustration.
- Keep the prototype read-only; use sample data only.

## Exploration

Three development-only variants are available on `/` via `?variant=pocket` (compact mobile), `?variant=desktop` (compact desktop), and `?variant=brief` (open editorial). The compact direction was preferred. The desktop companion now uses a charcoal-first palette, green secondary accents, subtle gradients, restrained frosted-glass surfaces, and larger type. English is the default interface language and IDR remains the currency. Final desktop feedback is still pending.
